# 版本 B 低難度改良實驗（2026-10-21）

## 試了什麼

| 改法 | 說明 |
| --- | --- |
| BM25 分數為 0 不參與 RRF（skip0） | 沒有任何詞比對到的切塊，BM25 名次是隨意排的，改成不給 BM25 分數 |
| 斷詞改用字元二元組（bigram） | 「請假期間」→ 請假／假期／期間，取代 jieba + 自訂詞 |
| 嵌入時加上 `##` 章節標題（ctx） | 例如「假別 > 病假」 |
| BM25 權重調低（w_bm25） | RRF 中 BM25 那一項乘上 0.2～1.0 |

## 結果

開發用問題集 30 題（Claude 依教材出題，每題 1～2 個應命中段落），K=3。
**注意：這份問題集只用來挑改法，不是報告第 4 節的評測集**；用同一份題目挑改法又拿來報命中率，結果會偏高。

| 版本 | hit@1 | hit@3 | MRR |
| --- | --- | --- | --- |
| A：向量（標題 + 內文） | 0.90 | **1.00** | **0.939** |
| 向量（章節 > 標題 + 內文） | 0.93 | 0.97 | 0.958 |
| 只用 BM25（jieba） | 0.57 | 0.73 | 0.665 |
| 只用 BM25（bigram） | 0.70 | 0.80 | 0.758 |
| B 初版：jieba，含 0 分 | 0.70 | 0.83 | 0.794 |
| B：jieba + skip0 | 0.73 | 0.90 | 0.825 |
| B：bigram，含 0 分 | 0.83 | 0.90 | 0.878 |
| **B 採用：bigram + skip0** | **0.83** | **0.97** | **0.892** |
| B：bigram + skip0 + ctx | 0.80 | 0.97 | 0.869 |
| B：bigram + skip0，w_bm25 = 0.2～0.5 | 0.80 | 0.97 | 0.869～0.881 |

## 採用

版本 B 改為 **bigram 斷詞 + BM25 為 0 不參與 RRF**；章節標題與權重調整沒有幫助，不採用。

## 觀察

1. **兩項改良都有效**：skip0 讓 hit@3 從 0.83 → 0.90（jieba）、0.90 → 0.97（bigram）；bigram 比 jieba 的 BM25 單獨命中率高（0.80 vs 0.73），且不需要維護自訂詞清單。
2. **但混合檢索仍沒有贏過純向量（版本 A）**。這份教材只有 33 段、每段主題明確，bge-m3 已經能處理大部分口語問法；BM25 只看字面，家長的用語常和教材不同（「發燒」vs「因病」、「帶什麼」vs「攜帶」），反而把排名拉偏。
3. **B 仍失敗的一題**：「下週校外教學要帶什麼？」→ P4-1-3, P4-1-1, P1-3-1（應為 P4-1-2）。
   「校外教學」的 bigram 在 P4-1-1、P4-1-3、P1-3-1 都有出現，而問題的「帶什麼」比對不到教材的「攜帶物品」（bigram「攜帶」≠「帶什」）。
