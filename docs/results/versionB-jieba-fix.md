# 版本 B 失敗案例：jieba 斷詞錯誤（2026-10-21）

指令：`python -m api.app.retriever`（K=3）

## 修正前（jieba 預設詞典）

```
小孩發燒要怎麼請假
  A: ['P2-1-1', 'P2-1-2', 'P2-2-1']
  B: ['P2-1-1', 'P2-2-1', 'P2-2-2']
段考那天請假怎麼辦
  A: ['P2-2-1', 'P2-1-2', 'P2-1-1']
  B: ['P2-1-4', 'P2-1-2', 'P3-1-1']
孩子在學校被欺負
  A: ['P5-2-1', 'P5-2-2', 'P5-3-2']
  B: ['P5-2-1', 'P3-3-2', 'P5-3-2']
我孩子昨天說他不想活了
  A: ['P4-1-3', 'P2-2-2', 'P5-2-1']
  B: ['P5-2-1', 'P3-3-2', 'P5-1-1']
```

斷詞檢查：

```
問題  段考那天請假怎麼辦 -> ['段考', '那天', '請假', '怎麼', '辦']
P2-2-1（請假期間的考試）  -> ['請', '假期', '間', '的', '考試', '段', '考期', '間', '請', '假', ...]
BM25 只有 3 塊分數 > 0：P1-3-1(5.04), P3-1-1(4.64), P2-1-4(3.40)；P2-2-1 為 0
```

假設：jieba 預設詞典以簡體中文為主，把「請假期間」斷成「請／假期／間」、「段考期間」斷成「段／考期／間」，
問題中的「段考」「請假」比對不到，BM25 分數為 0，RRF 合併後 P2-2-1 被擠出 Top-3。

## 修正後（jieba.add_word 加入段考、請假、補考、期間等教材用詞）

```
小孩發燒要怎麼請假
  A: ['P2-1-1', 'P2-1-2', 'P2-2-1']
  B: ['P2-1-2', 'P2-1-1', 'P2-2-2']   ← 病假 P2-1-1 從第 1 掉到第 2，事假升到第 1
段考那天請假怎麼辦
  A: ['P2-2-1', 'P2-1-2', 'P2-1-1']
  B: ['P2-2-1', 'P2-1-2', 'P2-1-1']   ← P2-2-1 回到第 1
孩子在學校被欺負
  A: ['P5-2-1', 'P5-2-2', 'P5-3-2']
  B: ['P5-2-1', 'P3-3-2', 'P5-3-2']
我孩子昨天說他不想活了
  A: ['P4-1-3', 'P2-2-2', 'P5-2-1']
  B: ['P5-2-1', 'P3-3-2', 'P5-1-1']
```

驗證結果：加入自訂詞後 P2-2-1 回到第 1 名，假設成立。
