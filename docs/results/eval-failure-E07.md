# 版本 B 失敗案例：E07 用詞與教材不同（2026-10-28）

指令：`python eval/run_eval.py`（K=3）

| 問題 | 應命中 | 版本 A | 版本 B |
| --- | --- | --- | --- |
| 孩子覺得考卷改錯了，可以請老師重看嗎？ | P3-2-3 | P3-2-3, P3-3-2, P3-1-3 V | P3-3-2, P3-1-2, P5-2-1 X |

## 假設

家長說「考卷」「老師」「重看」，教材 P3-2-3 寫的是「答案卷」「任課教師」「重新核對」，bigram 完全沒有重疊，P3-2-3 的 BM25 為 0。
依 skip0 規則，P3-2-3 只拿到向量那一項的 RRF 分數；其他段落只因為「孩子」「可以」這種常見詞比對到，就多拿到 BM25 那一項，把 P3-2-3 擠出 Top-3。

## 驗證

印出問題斷詞與各段分數：

```
query tokens: 孩子 子覺 覺得 得考 考卷 卷改 改錯 錯了 可以 以請 請老 老師 師重 重看 看嗎
P3-2-3 dense=0.644(第 1) bm25=0.00(—)    重疊：無
P3-3-2 dense=0.611(第 2) bm25=3.20(第 4) 重疊：孩子、可以
P3-1-2 dense=0.566(第 5) bm25=2.53(第 5) 重疊：孩子、可以
P5-2-1 dense=0.532(第 10) bm25=3.21(第 3) 重疊：孩子、可以
```

RRF：P3-2-3 = 1/61 ≈ 0.0164；P3-3-2 = 1/62 + 1/64 ≈ 0.0318 → 假設成立：向量排第 1 的正解，因為 BM25 為 0 被只靠常見詞得分的段落超過。

## 可以再驗證的方向

- 把問題改成教材用詞「對成績有疑問，可以請任課教師核對答案卷嗎？」，看 B 是否命中。
- BM25 斷詞去掉「孩子」「可以」等常見詞（停用詞），看 P3-3-2、P5-2-1 的 BM25 是否歸 0、P3-2-3 回到 Top-3。
